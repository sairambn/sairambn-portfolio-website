# sairambn — Portfolio

**Sairam Nagarajan** · Data Analyst · Power BI · SQL · Python  
Live: [sairambn.vercel.app](https://sairambn.vercel.app)

Modern, deep-themed portfolio built with TanStack Start, React 19, Tailwind CSS v4.

## Features

- Deep charcoal + warm ember color system with layered gradients and glow shadows
- Impact stories from real Power BI work
- Projects with live links where available
- LinkedIn + GitHub + email integration
- Fully responsive, polished typography (Space Grotesk / DM Sans / JetBrains Mono)

## Stack

- TanStack Start + React 19
- Tailwind CSS v4
- TypeScript
- Vite

## Local development

```sh
npm i   # or bun install
npm run dev
```

## Deploy

Connect this repo to Vercel and set the production domain to `sairambn.vercel.app`.
Auto-deploys on every push to `main`.
